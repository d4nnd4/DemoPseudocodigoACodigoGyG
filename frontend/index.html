      Usar otro modelo
      
          
      El backend habla con la IA a través de backend/app/providers/. Elige la opción que
            encaje con tu modelo:
      
          
      
            
      
              
      1 · Otro modelo de Ollama
      
              
      # .env
OLLAMA_MODEL=qwen2.5-coder:7b
OLLAMA_MEM_LIMIT=7g
      
              
      Se descarga solo al arrancar (con reintentos).
      
            
      
            
      
              
      2 · Servidor compatible con OpenAI
      
              
      LLM_PROVIDER=openai
OPENAI_BASE_URL=http://gpu-box:8000/v1
OPENAI_API_KEY=x
OPENAI_MODEL=Qwen/Qwen2.5-Coder-7B-Instruct
      
              
      vLLM, LM Studio, llama.cpp, TGI, Groq, OpenRouter…
      
            
      
            
      
              
      3 · Anthropic (Claude)
      
              
      LLM_PROVIDER=anthropic
ANTHROPIC_API_KEY=...
ANTHROPIC_MODEL=...
      
            
      
            
      
              
      4 · API propia (espacio reservado)
      
              
      LLM_PROVIDER=custom
CUSTOM_BASE_URL=http://mi-servidor:9000
CUSTOM_MODEL=mi-modelo
      
              
      Implementa stream() en providers/custom.py.
